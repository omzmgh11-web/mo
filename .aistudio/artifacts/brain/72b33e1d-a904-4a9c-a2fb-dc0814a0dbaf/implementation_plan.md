# خطة تعزيز المؤثرات الصوتية والإشعار السحابي الفوري 🎧☁️

تهدف هذه الإضافة إلى تعزيز تجربة التعلم التفاعلي بحسب اختياراتك: إضافة مؤثرات صوتية حقيقية (نطق فرنسي نقي، أصوات لطيفة للنجاح والخطأ)، مع إشعار سحابي أخضر أنيق يظهر فورياً عند كل حفظ تلقائي ليمنحك راحة بال تامة بأن كلماتك وتقدمك في أمان.

---

### قرارات المستخدم المؤكدة (User Review & Critical Decisions)

> [!IMPORTANT]
> تم تأكيد التفضيلات التالية بناءً على إجاباتك:
> 1. **المؤثرات الصوتية الحقيقية**: تفعيل أصوات النطق للكلمات الفرنسية (عبر Web Audio API + SpeechSynthesis بتوليف فرنسي أصيل) بالإضافة إلى نغمات تفاعلية محفزة وخفيفة عند الضغط على «عرفتها ✅» ونغمة تنبيه لطيفة غير مزعجة عند «غلطت ❌» مع زر تحكم لكتم/تشغيل الصوت.
> 2. **إشعار الحفظ السحابي**: إشعار سحابي أخضر عائم وأنيق يظهر لثانيتين عند كل حفظ تلقائي (`تم الحفظ في السحابة بنجاح ☁️✓`) دون إعاقة تركيز المستخدم.

## 1. نظرة عامة وتجربة المستخدم (UX Flow)

```
┌─────────────────────────────────────────────────────────────────┐
│                        تجربة التعلم التفاعلية                   │
│                                                                 │
│  [ بطاقة الكلمة ] ───(نطق فرنسي تلقائي أو يدوي)                 │
│         │                                                       │
│         ├───> ضغط [عرفتها ✅] ───> صوت نجاح مبهج + تأثير بصري   │
│         │                                                       │
│         └───> ضغط [غلطت ❌]   ───> صوت تنبيه خفيف + اهتزاز خفيف │
│                                                                 │
│  [ تعديل كلمة / تقدم درس ] ───> حفظ فوري ───> [ ☁️ تم الحفظ بالسحابة ] │
│                                             (شريط أخضر أنيق يختفي)│
└─────────────────────────────────────────────────────────────────┘
```

### المسار التعليمي:
1. **أصوات تفاعلية محفزة**:
   - توليد نغمة نجاح رنانة ودافئة (Harmonic Chime) عند حفظ الكلمة بنجاح عبر Web Audio API (تضمن عمل الصوت على أي جهاز دون الحاجة لتحميل ملفات صوتية خارجية قد تفشل).
   - نغمة هادئة تنبيهية (Soft Thud / Minor Tone) عند الضغط على غلطت لتنبيه الذاكرة دون إحباط.
   - زر تحكم سريع بالصوت (كتم / تفعيل 🔊) في الشريط العلوي وفي وضع التركيز.
2. **نظام النطق الفرنسي الحقيقي (Native French TTS)**:
   - تحسين اختيار الصوت الفرنسي من قائمة الأصوات المتاحة في جهاز المتصفح (تفضيل أصوات Google French / Thomas / Amelie الفرنسية الأصلية).
3. **مؤشر وإشعار الحفظ السحابي الأخضر (Cloud Sync Toast)**:
   - إشعار أخضر مصغر يظهر في أعلى/أسفل الشاشة بعبارة `تمت المزامنة وحفظ التعديلات في السحابة ☁️` مع وميض أيقونة السحابة الخضراء في الهيدر.

## 2. الهيكل البرمجي والتقني (Technical Architecture)

```
┌─────────────────────────────────────────────────────────────┐
│                    Sound & Cloud Service                    │
├──────────────────────────────┬──────────────────────────────┤
│      Audio Engine (WebAudio) │    Cloud Sync Hook           │
│  • playSuccessSound()        │  • syncUserDataToFirestore() │
│  • playErrorSound()          │  • triggerCloudPillToast()   │
│  • speakFrench(word)         │  • green auto-sync badge     │
└──────────────────────────────┴──────────────────────────────┘
```

1. **مولد الأصوات (Web Audio Synthesizer)**:
   - إنشاء مولد صوت نقي وخفيف جداً باستخدام `AudioContext` القياسي لإنتاج نغمات Chime دافئة خالية من أي بطء شبكة.
2. **شريط الإشعار السحابي (Cloud Sync Notification)**:
   - حالة `cloudSaveStatus` تظهر شريطاً زجاجياً أخضر شفاف (`bg-emerald-600/90 text-white backdrop-blur-md`) ينبثق برفق ويتلاشى تلقائياً بعد 2.5 ثانية.
3. **أمان البيانات**:
   - لا مساس بأي بيانات سابقة أو بنية الدروس والكلمات.
